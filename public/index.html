Paste your Tripo key (a long code that starts with tsk_). It stays on this computer, stored safely, and is only sent to Tripo.

Where do I find this?

  1. Press Where do I find this? above. Your web browser opens the key page.
  2. Sign in, or make a free account.
  3. Press Create, copy the long code it shows, then come back here and paste it below.

A key is like a password that lets Flatform make 3D models on your account. Each model uses a few credits from it.
